# Paper figures

Generated by `.venv/bin/python paper/scripts/figures/plot_all.py` from `image/log`. Do not edit by hand: the script rewrites this file and the figure folders. Each figure is a vector PDF (fonts embedded) plus a 600-DPI PNG. Single-panel figures are one IEEE column wide (3.5 in) and `runtime/runtime_overview` is the full text width (7.16 in).

- One script per figure type in `paper/scripts/figures/` (see the folder name below).
- Runtime figures use every run, because re-runs of a map differ in wall-clock time.
- Lifetime and energy figures use one run per map, because re-runs repeat the same deterministic simulation.
- Runtime means cover the first 1,000 rounds.
- A hatched bar, a hollow marker or a leading ≥ marks a metric not reached before the end of the run. Its value is the last logged round (a lower bound).
